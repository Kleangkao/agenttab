# `@agenttab/core`

Policy engine and execution state machine for AgentTab.

Usually you do **not** depend on this directly — use
[`@agenttab/fetch`](https://www.npmjs.com/package/@agenttab/fetch) in the agent
and run the gateway from https://github.com/Kleangkao/agenttab.

```bash
pnpm add @agenttab/core
```

See [docs/ADOPT.md](https://github.com/Kleangkao/agenttab/blob/main/docs/ADOPT.md).
