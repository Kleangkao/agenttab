# `@agenttab/x402`

AgentTab helpers around standard x402 payment flows (request binding, funding
hooks) used with the official `@x402/*` packages.

Prefer [`@agenttab/fetch`](https://www.npmjs.com/package/@agenttab/fetch) for
agent integration.

```bash
pnpm add @agenttab/x402
```

See [docs/ADOPT.md](https://github.com/Kleangkao/agenttab/blob/main/docs/ADOPT.md).
