# Vendored fonts

IBM Plex Sans and IBM Plex Mono (latin subset, weights 400/600), copied from
`@fontsource/ibm-plex-sans` and `@fontsource/ibm-plex-mono`.

Copyright 2017 IBM Corp. Licensed under the SIL Open Font License, Version 1.1:
https://openfontlicense.org

Served by the gateway at `/ui/fonts/*` so the operator console never depends on
an external font host. To refresh, re-copy the `-latin-<weight>-normal.woff2`
files from those packages.
